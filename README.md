# Консольный калькулятор с историей операций

Итоговый проект по Python. Кейс 1.

## Описание

Консольное приложение на Python для выполнения математических операций
с сохранением истории вычислений. Поддерживает работу с целыми и
десятичными числами, непрерывный ввод значений для выбранной операции
и подробное логирование действий.

## Возможности

### Математические операции
- **Сложение** (`+`) — пункт меню 1
- **Вычитание** (`-`) — пункт меню 2
- **Умножение** (`*`) — пункт меню 3
- **Деление** (`/`) — пункт меню 4
- **Возведение в любую степень** (`^`) — пункт меню 7
- **Извлечение квадратного корня** (`sqrt`) — пункт меню 8

### Непрерывный ввод
- В операциях `+`, `-`, `*`, `/` можно вводить числа одно за другим —
  каждое следующее число применяется к текущему результату.
- В возведении в степень можно вводить пары «основание — показатель»
  в цикле.
- В квадратном корне можно обрабатывать числа одно за другим.
- Остановка — пустая строка или слово `stop` (также `стоп`, `q`, `exit`,
  `выход`).

### Работа с числами
- Ввод чисел с точкой или запятой (`2.5` и `2,5` равнозначны).
- Точные вычисления с `Decimal` (28 значащих цифр).
- Форматирование результата без лишних нулей.

### История и логирование
- Каждая операция автоматически сохраняется в `history.txt` с датой
  и временем.
- Просмотр истории из меню (пункт 5).
- Очистка истории с подтверждением (пункт 6).
- Логирование действий и ошибок в `calculator.log`.

### Обработка ошибок
- Деление на ноль.
- Квадратный корень из отрицательного числа.
- Переполнение при возведении в степень.
- Пустой ввод, некорректные числа, `NaN` и бесконечности.
- Ошибки чтения/записи файлов истории и логов.
- Некорректный пункт меню.

## Требования

- Python 3.8+
- Сторонние библиотеки не требуются (только стандартная библиотека).
