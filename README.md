# Консольный калькулятор с историей операций

Итоговый проект по Python. Кейс 1.

## Описание
Консольное приложение выполняет базовые математические операции:
- сложение;
- вычитание;
- умножение;
- деление.

Поддерживается работа с целыми и десятичными числами. История операций
сохраняется в файл `history.txt` и может быть просмотрена из меню.

## Возможности
- ввод чисел через запятую или точку;
- точные вычисления с `Decimal`;
- сохранение истории с датой и временем;
- просмотр истории;
- очистка истории с подтверждением;
- обработка деления на ноль;
- обработка некорректного ввода;
- логирование действий в `calculator.log`.

## Требования
- Python 3.8+
- сторонние библиотеки не требуются

## Запуск
```bash
python calculator.py
